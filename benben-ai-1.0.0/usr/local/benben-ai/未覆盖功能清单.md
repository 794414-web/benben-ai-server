# 未覆盖功能清单（待补充的语音控制能力）

> 来源：系统 prompt 中提到、但当前工具列表（`指令手册.md`）尚未暴露的能力。
> 一旦奔奔 App 后续版本暴露了这些工具，可在 `fake_llm_server.py` 中按现有 `match_*` 模式补充对应的关键词匹配规则。

---

## 一、当前已支持（对照参考）

`fake_llm_server.py` 已实现 52 个工具，覆盖：

- 对话控制（1）
- 车辆状态读取（22）
- 导航控制（6）
- 媒体控制（2）
- 灯光控制（3）
- 空调控制（10）
- 车窗 / 天窗 / 遮阳帘控制（各 1）
- 车辆控制（3：后视镜折叠、驾驶模式、能量回收）
- 屏幕 / 显示控制（5）
- 音量控制（1）

## 二、尚未暴露 / 未实现语音控制的功能

以下能力在系统 prompt 中被提及，但工具列表中未出现，**当前无法通过语音指令控制**：

| 功能 | 类别 | 建议匹配关键词（参考） | 备注 |
|---|---|---|---|
| 座椅加热 | 舒适 | 座椅加热、加热座椅、座椅暖一点 | 可归入 `control_seat_heat` |
| 座椅通风 | 舒适 | 座椅通风、座椅吹风、座椅凉一点 | 可归入 `control_seat_vent` |
| 座椅按摩 | 舒适 | 座椅按摩、按摩座椅、开按摩 | 可归入 `control_seat_massage` |
| HUD 抬头显示 | 显示 | HUD、抬头显示、平视显示 | 开关 + 亮度 |
| 无线充电 | 充电 | 无线充电、手机充电、充电板 | 开关 |
| 香氛 | 舒适 | 香氛、车内香薰、气味、香水 | 开关 + 模式/浓度 |
| 行程历史 | 查询 | 行程记录、历史行程、去过的路线、行驶轨迹 | 只读查询 |

## 三、补充说明

- `get_seat_status`（座椅状态）已支持关键词识别，但**座椅加热/通风/按摩的「控制」工具未暴露**。
- 其余读取类工具（车门、车窗、空调、胎压等）均已支持关键词识别。
- 若未来 App 更新暴露上述工具，建议：
  1. 在 `fake_llm_server.py` 新增对应的 `match_*` 函数；
  2. 在 `process_request()` 的调度链中按顺序加入该函数；
  3. 用 `test_*.py` 模式补充回归测试；
  4. 同步更新 `指令手册.md` 与本文档。
