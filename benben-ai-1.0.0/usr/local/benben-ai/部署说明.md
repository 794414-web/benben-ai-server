# 车载AI助手「奔奔」— 免费假大模型服务 · 部署说明

> 本服务用关键词/正则匹配替换真实大模型，冒充 OpenAI 兼容的 Chat Completions API，
> 让车载语音助手「奔奔」在**不调用任何大模型 API** 的情况下完成车辆语音控制。

---

## 一、环境要求

- Python 3.10 及以上
- 一台能与车机（或测试手机）网络互通的机器（同局域网即可）

## 二、安装依赖

项目已提供 `requirements.txt`：

```bash
pip install -r requirements.txt
```

依赖清单：

| 依赖 | 用途 |
|---|---|
| `fastapi` | Web 服务框架，提供对话接口与管理 API |
| `uvicorn[standard]` | ASGI 服务器，真正拉起服务 |
| `pydantic` | 请求/响应数据模型 |

## 三、启动服务

```bash
python fake_llm_server.py
```

启动后控制台会打印类似：

```
服务地址: http://0.0.0.0:9998
管理面板: http://0.0.0.0:9998/admin
默认管理员密码: admin123456
```

## 四、配置项（环境变量，均可选）

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `BIND_HOST` | `0.0.0.0` | 监听地址。公网部署建议改为具体内网 IP 或 `127.0.0.1` |
| `CORS_ALLOW_ORIGIN` | `*` | 允许的跨域来源。生产环境应改为车机/前端实际域名，如 `http://192.168.1.54:9998` |
| `PORT` | `9998` | 监听端口（如需改动需同步修改下方 App 配置） |

示例（收紧跨域与绑定）：

```bash
BIND_HOST=127.0.0.1 CORS_ALLOW_ORIGIN=http://192.168.1.54:9998 python fake_llm_server.py
```

## 五、首次使用（重要）

1. **默认管理员密码为 `admin123456`**，存在 `config.json` 中（SHA256 + 随机 salt）。
2. 出于安全考虑，服务启动后**首次登录必须修改密码**——在仍使用默认密码期间，除「修改密码」接口外，其余管理操作一律返回 `403`。
3. 浏览器打开 `http://<你的IP>:9998/admin` → 用默认密码登录 → 立即修改密码。

## 六、多用户与 App 配置

1. 登录管理面板后，进入「用户管理」→ 创建用户（填写名称/备注）→ 复制生成的 **Token**。
2. 在奔奔助手的设置中，把大模型服务配置改为：

   | 配置项 | 值 |
   |---|---|
   | 服务地址 | `http://<你的IP>:9998/compatible-mode/v1` |
   | API Key | 刚才复制的 **Token** |
   | 模型名称 | 任意（如 `qwen`、`fake-model`） |

3. 点击「测试对话」，若返回「连接成功」即配置正确。
4. 之后即可用自然语言语音指令控制车辆（支持 52 个工具、200+ 表达，详见 `指令手册.md`）。

> 说明：同时兼容 `/v1/chat/completions` 路径，部分旧版客户端可直接用 `http://<IP>:9998/v1`。

## 七、管理面板功能

| 功能 | 说明 |
|---|---|
| 用户列表 | 查看所有用户、调用次数、启用状态 |
| 创建 / 编辑 / 删除用户 | 增删用户、启用禁用、改名改备注 |
| 重置 Token | 为用户重新生成 Token（旧 Token 立即失效） |
| 用量日志 | 按用户查看历史指令与匹配到的工具（`usage_logs/`） |
| 重启服务 | 通过 `/api/service/restart` 热重启 |

## 八、调试 / 测试脚本

| 脚本 | 用途 |
|---|---|
| `test_temp.py` | 回归测试「温度调到 24 度」等温度类指令，验证不再误匹配为导航 |
| `test_rw_match.py` | 测试 remote_watch 系列（远程控车）17 个工具的匹配规则 |
| `check_resp.py` | 查看指定请求/响应的详细内容 |
| `list_logs.py` | 列出最近的请求日志摘要 |
| `proxy_mock.py` | **初次抓包分析用**：端口 9999，拦截 App 发出的请求、记录其暴露的工具定义。**注意**：其关键词是占位用的「开灯/关灯」等通用词，与实际奔奔工具对不上，不能当正式服务使用 |

## 九、安全注意事项

- **首次务必改密**：默认密码 `admin123456` 为公开值，未改密时所有管理操作被强制拦截。
- **公私分明**：`BIND_HOST` 默认 `0.0.0.0`（监听所有网卡），若机器有公网暴露风险，请改为具体地址或仅监听内网。
- **收紧 CORS**：`CORS_ALLOW_ORIGIN` 默认 `*`，生产环境请改为车机实际来源。
- **密码存储**：`config.json` 中的密码为「随机 salt + SHA256」，非明文；但配置文件本身应妥善保管，不要外传。
- **Token 即凭证**：用户 Token 等同于其调用权限，重置后旧 Token 立即失效。

## 十、已知限制

- 匹配基于关键词/正则，无法理解复杂语义、上下文指代或模糊表达；遇到未匹配的指令会返回随机简短回复（如「好的，我在听。」）。
- 部分车辆功能（座椅加热/通风/按摩、HUD、无线充电、香氛、行程历史）尚未暴露工具，详见 `未覆盖功能清单.md`。
- 服务为单机运行，未做高可用与水平扩展。
